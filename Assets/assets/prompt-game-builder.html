Cara pakai

  1. Pilih kustomisasi. Atur genre, tema, karakter, dan fitur sesukamu.
  2. Salin prompt. Prompt tersusun otomatis di kolom sebelah kanan.
  3. Tempel di AI. Buka ChatGPT, Claude, atau Gemini, lalu tempel dan kirim.
  4. Mainkan game-mu. Simpan kode HTML yang dihasilkan sebagai file .html, lalu buka di browser.

Tanya jawab

Apakah website ini membuat game langsung?

Tidak. Website ini hanya menyusun prompt. Game dibuat oleh aplikasi AI yang kamu pilih.

Bagaimana cara memainkan hasilnya?

Salin kode dari AI ke Notepad atau editor teks, simpan dengan nama game.html, lalu buka file itu di browser.

Bagaimana cara menyimpan game hasil AI?

Prompt sudah meminta satu file HTML. Salin kode dari AI, tempel di Notepad atau editor teks, simpan dengan nama game.html, lalu buka di browser. Di HP, salin kodenya ke aplikasi Catatan atau File, lalu ganti ekstensinya menjadi .html.

Apakah game bisa dimainkan tanpa internet?

Bisa. Setelah file game.html tersimpan, game berjalan langsung di browser tanpa internet.

Hasilnya kurang sesuai, apa yang harus dilakukan?

Kirim revisi di chat yang sama, misalnya "buat musuhnya lebih lambat" atau "ganti warna latar jadi biru".
